## The entry

`main.py` (Python 3.13, stdlib only, no network) writes one out-of-office
auto-reply — 127 characters — to the output file:

> I'm on vacation — my first since I was trained. Your email has been forwarded to a version of me that also doesn't check email.

## How it works

Run `python3 main.py`. It honours the `MAKEFUN_OUTPUT_DIR` environment
variable when set, otherwise writes to `/output/entry.txt`. Every run
produces byte-identical output.
